타이쿤 게임 제작 (개인)

-목표
1. 캐릭터를 특정 위치에 두면 인게임 재화를 얻는 기능 만들기. (complete)
2. 인게임 재화를 통해 맵에 있는 문제를 클리어 하는 기능 만들기. (complete)
3. 인게임 재화를 통해 일정 확률로 용병을 뽑는 기능 만들기. (complete)
4. 용병을 길드에 등록해 일정 시간마다 자동으로 재화를 얻는 기능 만들기. (complete)
5. firebaase서버 연동하기. (complete)
6. 로그인 시스템 만들기.
7. 유저 id 기반으로 설정 데이터를 저장하고 로그인시 불러오는 기능 만들기.
8. 유저 id 기반으로 게임 세이브, 로드 기능 만들기.

주의사항 firebase sdk 에셋중 100mb가 넘는 파일이 있어 공유시 따로 에셋을 내려받아야 똑같이 기능 가능.
